Inside the combined model the Isolation Forest flags 0 scam payments and 23 genuine payments that LightGBM alone did not flag. Section 5 tests whether it helps on scam types the model was never trained on.

## Limits

- Training data, test data and stress populations all come from one simulator written by the team. The stress test changes two assumptions against us, but it cannot replace real transactions.
- The September test month has few scam payments, so one payment moves recall by about two points. Read the intervals, not the point values.
- Scams are injected far more often than in real life. Precision and the calibrated probabilities would be lower at a real base rate. False pauses per customer per month do not depend on that rate.
- Performance on real customers is not yet measured. The validation roadmap is in `docs/validation_roadmap.md`.
